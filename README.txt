# Bhargavi & Venu Gopal — Digital Engagement Invitation

This is a ready-to-deploy static website.

## What it does
- Full-screen vertical invitation pages
- Smooth section-to-section scrolling
- Automatic scrolling after "Open Invitation"
- Music starts after the user taps "Open Invitation" (browser autoplay rules require interaction)
- Music toggle
- Location button opens the Google Maps link supplied for the invitation
- Works without VS Code or a backend

## Deploy
Upload the whole folder to any static hosting service. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.

## Important
The background music included here is a lightweight browser-generated instrumental. If you want a real song, replace the music function in `script.js` with an MP3/audio file you have permission to use.

The invitation artwork is displayed as full-page backgrounds, so visitors experience it as one continuous website rather than a gallery of separate images.
